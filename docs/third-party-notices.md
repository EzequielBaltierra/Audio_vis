# Third-party notices

## Pathfinder concept

The finite rail-background simulation in `src/ascii/pathfinder.js` is
adapted from **Pathfinder** by Alex Miller, published in the
[`ertdfgcvb/play.core`](https://github.com/ertdfgcvb/play.core) ASCII playground.
The upstream project is distributed under the
[Apache License 2.0](https://github.com/ertdfgcvb/play.core/blob/main/LICENSE).

This adaptation replaces the playground runtime and pointer spawning with a
React mount lifecycle, fixed-duration rendering, reduced-motion behavior, and a
non-interactive presentation layer.
